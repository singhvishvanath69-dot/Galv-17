Teacher App

रोज़ के कागज़-कलम वाले काम को डिजिटल में बदलें

  • ✍️ Rich Text Editor से Paper बनाएं — Bold, Color, Size, तस्वीरें और गणितीय फॉर्मूला (LaTeX) तक शामिल
  • 🗒️ अलग से Notes बनाएं और सुरक्षित Save रखें
  • 📊 Mark Sheet — विषय जोड़ें, अंक भरें, Total अपने-आप बन जाए
  • 📝 Test Result — पहले Session में Save करें, तैयार होने पर Publish करें
  • 📁 Papers, Notes, Mark Sheets और Results की पूरी History एक जगह
  • 🖨️ सीधा Print करें, या तुरंत Share करें
🎓

Student App

Students खुद अपना Result घर बैठे देख सकते हैं

  • 🔎 Registration Number और Class डालकर पूरी Class का Scoreboard देखें
  • 🎯 Roll Number और Class डालकर अपना व्यक्तिगत Result देखें
  • 📱 कहीं से भी, किसी भी डिवाइस से Result चेक करें
  • 🔒 सिर्फ Teacher द्वारा Publish किया गया Result ही दिखता है
